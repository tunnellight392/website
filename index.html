Selected work

Every app below is public. The repository name is the link; the two on Google Play link there as well.

  • stop-scroll Android · Kotlin

    Stop Scroll

    Measures the time you actually spend scrolling a feed, rather than the time the app sits open in front of you.

    • Separates active scrolling from idle time through an AccessibilityService
    • Different idle rules for list feeds (Reddit, YouTube) and full-screen video (TikTok, Reels, Shorts)
    • Week-over-week and month-over-month comparisons, with honest clipping of partial periods
    • Charts drawn directly on Canvas — no charting dependency

    Kotlin · Jetpack Compose · Material 3 · Room

  • converter-app Android · Kotlin

    Unit Converter

    Twenty categories of everyday conversion. Currently at v1.2.0, with the store listing and release notes kept in the repository alongside the code.

    • Length, mass, temperature, area, volume, speed, fuel economy, EV efficiency, pressure, power, pay, shoe and shirt sizing
    • Search matches unit names and symbols — psi, mpg, knot
    • Long-press a row to copy it; the last value in each category is remembered
    • Conversion tables covered by unit tests

    Kotlin · Material 3 · JUnit

  • promises_ios iOS · Swift

    Promises for iOS

    The same app rebuilt natively in SwiftUI — a second implementation, not a port of the first.

    • Today's verse set over photography; swiping moves through the collection and changes the image
    • Serif or sans face, adjustable text size, and Dynamic Type honoured throughout
    • Favourites and notification scheduling via @AppStorage and observable stores
    • Shares its translation set with the Android build

    Swift · SwiftUI · UserNotifications

  • airport-terminal-app Android · Kotlin

    Airport Terminal

    Terminal and concourse layouts for 119 airports, from Atlanta's Plane Train concourses outward.

    • 119 airports with terminals, concourses and gate ranges in bundled JSON
    • An interactive terminal map drawn on a custom View
    • Links out to each airport's official map for the detail it can't carry

    Kotlin · Custom Canvas views · Local JSON

Notes on the work

Three things the repositories show, if you'd rather not read them.

  • The same app, written twice

    Promises runs on Android in Java and on iOS in SwiftUI. Two separate implementations sharing a translation set — the iOS build uses @AppStorage, observable stores and Dynamic Type rather than reproducing the Android structure in Swift.

  • Drawing rather than depending

    Stop Scroll's charts and Airport Terminal's maps are drawn on Canvas in custom views. Both could have pulled in a library; drawing them directly kept the binaries small and left nothing to chase when the OS moves.

  • Finished to the store, not the build

    Unit Converter is at v1.2.0 with its Play Store listing and per-version release notes versioned next to the code, conversion tables under unit tests, and a feedback screen wired up in the app itself.
