Airport Terminal

Which concourse, which gate range, and how the terminals sit relative to each other — for 119 airports, held locally so it answers before the airport wifi has finished arguing with you.

airport-terminal-app
  • 119 airports with terminals, concourses and gate ranges in bundled JSON
  • An interactive terminal map drawn on a custom View
  • Links out to each airport's official map for the detail it can't carry

Kotlin · Custom Canvas views · Local JSON

How it works

119 airports, bundled

Terminals, concourses and gate ranges ship with the app as JSON rather than being fetched. That makes it instant, and it makes it work airside on a dead connection, which is exactly where the question gets asked.

The map is drawn, not imported

The terminal map is rendered on a custom View. Shipping an image per airport would have meant 119 images to keep current and a large binary to carry them; drawing from the same structured data that answers the gate questions keeps the layout and the facts in step.

Knowing what it can't tell you

It does not try to be the airport's own map. For the detail a bundled layout cannot carry — which gate the lounge is behind, where the walkway is closed this month — each airport links out to its official map.

A static page — no build step, served straight from the repository.
